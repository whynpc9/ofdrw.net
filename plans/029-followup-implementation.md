Implemented `OfdToHtmlConverter`/`OfdHtmlOptions` inside the existing SVG assembly and the explicit `ofd-to-html` CLI partial. The Reader is invoked once; selection is snapshotted before awaiting, validated, and emitted in occurrence order. The existing single-page SVG entry point keeps its behavior. The shared renderer accepts an optional operation-local HTML context for conservative generation reservations, strict source drawing admission, scoped clip IDs, scoped fonts and content/face font parsing cache. 014/015 are already present at this baseline; controlled alpha/dash output is retained in the HTML policy.

Output uses a bounded private segmented memory spool instead of the proposed disk spool. This keeps sensitive plaintext out of shared temporary directories while retaining pre-copy output protection. It is a deliberate implementation adjustment, not a promise of hard process memory limits. The caller's streams stay open at their current positions; final copy/flush exceptions and cancellation may leave a prefix. CLI commits through the existing `AtomicOutput` owner.

Budgets include shell/title, conservative intermediate character/node capacity, actual UTF-8 global/section bytes, original embedded resources, and cumulative decoded image pixels. Duplicate page/image occurrences are charged again. Repeated font resource declarations sharing one content/face are parsed once and emitted once per occurrence. PNG/JPEG have a narrow no-new-dependency admission path: static non-interlaced PNG framing/CRC, zlib scanlines/filter bytes and Adler checksum; single-scan 8-bit baseline Huffman JPEG segment/table and entropy traversal. Expansion is charged by pixels before PNG inflation/JPEG entropy traversal, with cancellation checks in the loops. Unsupported encodings/chunks fail explicitly. These are bounded syntax checks, not a universal image sanitizer or browser decoder certification.

See [public usage and supported boundaries](../docs/html-preview.md). Static HTML carries escaped title/text, trusted CSS, defensive CSP and only the renderer's approved SVG element/attribute/value forms. It does not export actions or claim arbitrary OFD/Word fidelity.

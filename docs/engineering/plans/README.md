## Findings considered and rejected

- **PDF vector import counts identical fonts once per page against `MaxTotalFontBytes`.** By design: `docs/architecture/pdf-vector-design-contract.md:41` states "MaxTotalFontBytes只按成功SnapshotText+Add引用资源累计输出，多页/重复selection/不同ID不去重" (output is accumulated per successfully referenced resource; multiple pages, repeated selections and different IDs are not de-duplicated). Revisit only through that design contract.
- **Process-wide PDF font registry never evicts.** This is a documented limit (`conversion-contracts.md:71`), so it is not planned as a fix. It is planned as a spike (014) because it is an operational cliff for long-running services.
- **ImageSharp 2.1.13 advisories, BouncyCastle exact pin, CS1591 suppression, `TreatWarningsAsErrors=false`, delegated SES/SM2 verification**: recorded decisions (D10, `password-crypto.md:59`, `check-public-api-docs.py`, roadmap). Plan 013 allowlists D10 explicitly instead of reopening it.
- **CLI `AtomicOutput.DisposeAsync` deletes the temp file only after a successful stream dispose.** Low impact (it needs a flush failure after an already-failed conversion); not worth a plan.
- **Blocking waits in `OwnedProcessGroup` / `ExternalProcessRunner`.** Real, but intricate audited code, and the impact depends on load. Revisit only with evidence of thread-pool starvation.
- **Reader ignores declared `<PageRes>` locations (uses the sibling `PageRes.xml` convention).** Needs evidence that real producers use other names; the writer, pruner and cleaner all share the convention. Follow-up candidate.
- **Font matching uses canonical numeric IDs in one place and exact strings in another.** Medium confidence; needs a trace through every converter. Follow-up candidate.
- **Composite cycle check does not descend into PageBlock children.** Cycles are still caught at render time (`OfdCompositeProjection.cs:43`). Low leverage.
- **`OfdPackageStructureChecker` path resolution differs from `OfdPackagePath`.** Changing it alters validation results; recorded as a follow-up in plan 007.
- **Timing-sensitive tests (Audit024, Unix supervisor, password cancellation).** Not correlated with actual CI failures; loosening them risks hiding regressions.
- **Coverage collection, CI flag de-duplication, central package management, scripts README, `.editorconfig`/analyzers, broken relative links in `docs/evidence/*/README.md`.** Low leverage relative to the plans above. Bulk analyzers would be noisy in an 80k-line codebase.
- **Migrating PdfSharpCore / PdfPig / MigraDocCore / Docnet.** Belongs with the roadmap's deferred backend/TFM decision (D10); high visual re-acceptance cost.
- **DOCX style resolution re-serializes XML per run; OFD→PDF re-decodes repeated images.** Real performance costs, but unmeasured; plan only after profiling a representative document.
- **R22 general text pipeline, PDF vector in the CLI.** Roadmap items that the roadmap deliberately leaves unscheduled; maintainer's call.

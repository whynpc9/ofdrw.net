`0.5.1` 已通过 NuGet Trusted Publishing 发布。源码标签 `v0.5.1` 指向 `ab01d8711e0e37374925681798cf1bcf3b065e23`。14 个公开包已通过签名校验和隔离消费 E2E。[GitHub Release](https://github.com/whynpc9/ofdrw.net/releases/tag/v0.5.1) · [发布工作流](https://github.com/whynpc9/ofdrw.net/actions/runs/45317916528) · [发布记录](https://github.com/whynpc9/ofdrw.net/blob/main/docs/validation/0.5.1-publication-2026-11-24.md)

0.5.1 是 0.5.0 的补丁版本。变更来自 [PR #150](https://github.com/whynpc9/ofdrw.net/pull/150)。

## 相比 0.5.0

- PDF 导出使用源文档的命名空间解析注释外观，修复 `/2016` 文档中新投影的注释裁剪回退到短命名空间的问题。PDF 和 SVG 共享页面绘制顺序、字体面选择、显式字形轮廓定位和路径分词。
- OFD 文本提取会展开注释外观中的复合对象。依赖提取文本或标注检索结果的调用方可能看到额外的文字。
- 归档预检、Archival 与 Medical 复用有界 XML 读取和资源范围检查。Medical 会纳入隐式的同目录 `PageRes.xml`。含百分号转义的引用无法解析，无法解析的 DocRoot 作为范围缺口报告。
- 栅格转换适配命名空间时保留字体嵌入选项。编辑入口共享包级选项复制和包引用定位逻辑。

## 兼容性与依赖

普通 SDK、Archival 和 Medical 面向 `netstandard2.0` / `netstandard2.1`。CLI 需要 .NET 10。默认发布集合为 14 包，Archival 和 Medical 按需显式安装。同系列依赖精确锁定到同批版本，请一起升级直接引用的 `Ofdrw.Net.*` 包。

```sh
dotnet add package Ofdrw.Net.Converter --version 0.5.1
dotnet tool install --global Ofdrw.Net.Cli --version 0.5.1
dotnet add package Ofdrw.Net.Archival --version 0.5.1
dotnet add package Ofdrw.Net.Medical --version 0.5.1
```

已安装 CLI 时使用 `dotnet tool update --global Ofdrw.Net.Cli --version 0.5.1`。

## 已知限制

固定样例验收的适用范围见[发布样例与配置](https://whynpc9.github.io/ofdrw.net/reference/release-profile-cn-en/)。复杂 Word 文档保真、Preview Find、原始 Unicode Copy、完整归档及医疗标准符合性仍受[能力边界](https://whynpc9.github.io/ofdrw.net/troubleshooting/known-issues/)约束。ImageSharp 2.1.13 的既有告警继续按[依赖评估](https://github.com/whynpc9/ofdrw.net/blob/main/docs/validation/d10-imagesharp-security-assessment.md)处理。

额外检查的 upstream 999 render-only 样例中，五页的税率百分号与右侧列边框相碰。五张页图与 0.5.0 的对应页图逐字节一致。

## 功能测试与视觉验收

- 本地全套 .NET 测试 5,490 通过、4 按环境跳过、0 失败。其中两项中文字体用例以固定字体补跑通过。强制可信字体门禁 74 项通过。14 个候选包和 SES 扩展通过隔离包消费 E2E。
- 固定 DOCX 的显式 Native 和默认模式各两页，OFD 与导出 PDF 均保留全部 189 个非空白源字符。独立视觉评审在 macOS Preview 检查两种模式的四页、OFD-H 四页和 Native RequireEmbedded 两页，也逐张检查对应的十张 PNG。四页核心样例通过 [Q05](https://github.com/whynpc9/ofdrw.net/blob/v0.5.1/docs/validation/releases/0.5.1-acceptance.json)。
- 公开包隔离消费重新生成了上述十页，PNG 与候选逐字节一致。Preview Find、原始 Unicode Copy 和 PDF 选择几何未验。

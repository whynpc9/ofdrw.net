`0.3.1` 是已发布的稳定版。源码标签 `v0.3.1` 指向 `f16ba8eaa0b6f034ae831770189897f807d1cee5`。12 个主包均已从公开 NuGet 下载并验证签名。参见[发布工作流](https://github.com/whynpc9/ofdrw.net/actions/runs/42745363967)及[发布记录](https://github.com/whynpc9/ofdrw.net/blob/main/docs/validation/0.3.1-publication-2026-11-10.md)。

## 相比 0.3.0

- 位图骑缝章导出 PDF 时，仅将与当前切片相交的像素写入图像资源，并保留切片的精确裁切边界，避免相邻切片的颜色经插值出现在接缝上。
- 嵌套 OFD 骑缝章生成每个切片的 PDF Form 时，跳过确定完全落在切片外的无描边、无对象变换填充路径。其余图元继续使用精确裁切。修复也覆盖经 PDF 路径生成的严格 PNG。
- 补充混合大小写归档路径、带前缀 ZIP、OFD 绘图与文字变换、骑缝章及严格图像导出的回归覆盖。参见[转换契约](/reference/conversion-contracts/)。

## 兼容性与依赖

SDK 继续面向 `netstandard2.0` 和 `netstandard2.1`，CLI 要求 .NET 10。公开 API、依赖版本与 12 个默认发行包保持一致。ImageSharp 2.1.13 的五项已披露依赖告警仍适用。参见[依赖评估](https://github.com/whynpc9/ofdrw.net/blob/main/docs/validation/d10-imagesharp-security-assessment.md)。

## 已知限制

骑缝章修复及回归结论适用于已检查的位图和嵌套 OFD 样例。macOS Preview Find、原始 Unicode Copy 和段落 PDF 选择几何仍无通过结论。包内 README 的安装示例仍写 `0.3.0`，请使用下方的 `0.3.1` 命令。其它限制见[已知问题](/troubleshooting/known-issues/)。

## 安装

```sh
dotnet add package Ofdrw.Net.Converter --version 0.3.1
dotnet tool install --global Ofdrw.Net.Cli --version 0.3.1
```

已安装 CLI 时，使用 `dotnet tool update --global Ofdrw.Net.Cli --version 0.3.1`。其它包见[安装与包选择](/getting-started/installation/)。

## 验收范围

三平台 CI、同批包消费和候选 Q05 逐页验收均已通过。公开包重新生成的两种 DOCX 模式和两类骑缝章共 12 张 PNG 与候选逐字节相同。公开包 SHA-256 见 [GitHub Release](https://github.com/whynpc9/ofdrw.net/releases/tag/v0.3.1)。

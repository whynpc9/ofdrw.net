`0.4.0` 是已发布的稳定版。源码标签 `v0.4.0` 指向 `9244b19a9ab29fe8edf80fa569797b8087423fa3`。12 个默认包均已从公开 NuGet 下载并核对签名与发布产物。参见[发布工作流](https://github.com/whynpc9/ofdrw.net/actions/runs/43793335928)和[发布记录](https://github.com/whynpc9/ofdrw.net/blob/main/docs/validation/0.4.0-publication-2026-11-16.md)。

## 相比 0.3.1

- HarfBuzz 复用同一字面的原生字体字节，减少重复复制和托管分配。段落引擎分别限制实际行数、试排构建和塑形次数，复用完整字素边界，保留已能排版输入的紧急断行顺序。90,000 个无断点字符的固定样例可在默认预算内完整排版。
- DOCX Native 的显式段落引擎会限制超出栏宽的首行或悬挂缩进，并报告一次 `DOCX_NATIVE_INDENT_LIMITED`；必要时取消正向首行缩进后重试。静态 CFF 转 TrueType 设有整字体运算和大小预算，并更明确地拒绝无效输入。PDF 导入的可选 RTL 行带检查保留原判定并减少重复扫描。
- CLI 阻止附件提取和预检报告覆盖同一输入，并在 Linux、macOS 上保留被替换文件的 Unix 权限。对来自输入的人读状态、列表和诊断字段转义控制字符。外部程序的裸名称仅从应用目录和绝对 PATH 项解析。
- 签名验证与其他包处理共用引用解析规则，识别允许的等价路径，并继续拒绝越出包根或指向不同条目的歧义路径。
- CLI 新增 `ofdrw areas list` 和 `ofdrw areas fill`。PDF → OFD 可显式使用 `--copy-bookmarks`、`--copy-attachments`。SDK 的图像出口支持透明 PNG 和自选 RGB 底色，默认仍为白底。参见[命名区域](/guides/named-areas/)、[PDF 导入元数据](/guides/pdf-import-navigation-attachments/)与[图像导出](/guides/images/)。

## 升级兼容性与依赖

- 转换、页面和查询命令会拒绝重复单值选项、多余位置参数、不适用的选项及带符号的页码。请按 [CLI 参考](/reference/cli/)修正依赖旧解析行为的脚本。人读输出的转义可能影响解析这些文本的脚本。结构化 JSON 与提取正文维持各自的输出契约。
- 同系列包的依赖采用精确范围 `[x.y.z]`。请一起升级 `Ofdrw.Net.*`。NuGet 对混装可能报错或产生 `NU1608` 警告，具体取决于直接引用和还原图，参见[安装与包选择](/getting-started/installation/)。
- 默认发布集合为 12 个包。普通 SDK 继续面向 `netstandard2.0` / `netstandard2.1`，CLI 要求 .NET 10。Skia、PDF Vector、Password 和 SES interop 为独立源码扩展。ImageSharp 2.1.13 的五项已披露告警仍适用，见[依赖评估](https://github.com/whynpc9/ofdrw.net/blob/main/docs/validation/d10-imagesharp-security-assessment.md)。

## 已知限制

紧急断行仍可能长距离试排。透明背景仅支持 PNG，CLI 的图像导出默认使用白底。命名区域填充限定为单文档、未签名的 OFD。独立的 macOS Preview Find、原始 Unicode Copy 和 PDF 选择几何限制见[已知问题](/troubleshooting/known-issues/)。

## 安装

```sh
dotnet add package Ofdrw.Net.Converter --version 0.4.0
dotnet tool install --global Ofdrw.Net.Cli --version 0.4.0
```

已安装 CLI 时使用 `dotnet tool update --global Ofdrw.Net.Cli --version 0.4.0`。

## 验收范围

三平台 CI、SES 与候选包消费均通过。macOS Preview 逐页复核固定 DOCX 的显式 Native 和默认模式，均沿 DOCX → OFD → PDF 查看实际两页产物。版式、字体和导出验收范围见[发布记录](https://github.com/whynpc9/ofdrw.net/blob/main/docs/validation/0.4.0-publication-2026-11-16.md)。公开包 SHA-256 见 [GitHub Release](https://github.com/whynpc9/ofdrw.net/releases/tag/v0.4.0)。

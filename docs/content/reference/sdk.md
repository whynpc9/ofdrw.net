| 入口 | 所属包 / 命名空间 | 说明 |
| --- | --- | --- |
| DocxToOfdConverter / DocxToPdfConverter | Converter.Docx.Converters | Native、DualLayer、渲染引擎 |
| PdfToOfdConverter / OfdToPdfConverter | Converter.Pdf.Converters | 双层导入和 PDF 导出 |
| OfdToSvgConverter | Converter.Svg.Converters | 单页 SVG |
| FlowDocument / Paragraph / Span | Layout | 流式排版 |
| OfdDocumentBuilder | Layout.Builders | 显式页面构建 |
| OfdPackageWriter | Packaging | 包写出 |
| OfdReader | Reader | 包读取、文本与结构 |

先按[快速开始](https://whynpc9.github.io/ofdrw.net/getting-started/quickstart/)运行最小示例，再查相关主题约定。完整公开成员的 XML 文档随程序集分发；此页是人工维护的入口索引，不是全量生成的 C# API reference。

资源预算、取消与错误语义见[转换约定](https://whynpc9.github.io/ofdrw.net/reference/conversion-contracts/)。文字查询、塑形和 typed writer 分别见[预排版](https://whynpc9.github.io/ofdrw.net/reference/text-prelayout/)、[typed 输出](https://whynpc9.github.io/ofdrw.net/reference/text-shaped-output/)和[混排](https://whynpc9.github.io/ofdrw.net/reference/text-mixed-paragraph/)。

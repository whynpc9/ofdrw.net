Ofdrw.Net 为 .NET 应用提供 OFD 生成、读取、编辑和格式转换，以及可扩展的签名完整性检查。

从[安装与包选择](https://whynpc9.github.io/ofdrw.net/getting-started/installation/)开始，或直接运行[快速开始](https://whynpc9.github.io/ofdrw.net/getting-started/quickstart/)。

## 按任务阅读

| 任务 | 入口 |
| --- | --- |
| 将 Word 文档转为 OFD | [DOCX 转换](https://whynpc9.github.io/ofdrw.net/guides/docx/)、[字体部署](https://whynpc9.github.io/ofdrw.net/guides/fonts/) |
| 生成报表 | [流式排版](https://whynpc9.github.io/ofdrw.net/guides/flow-layout/)、[表格](https://whynpc9.github.io/ofdrw.net/guides/public-tables/)、[绘图](https://whynpc9.github.io/ofdrw.net/guides/graphics/) |
| 转换和预览 OFD | [PDF 与 SVG](https://whynpc9.github.io/ofdrw.net/guides/conversion/)、[图片](https://whynpc9.github.io/ofdrw.net/guides/images/)、[HTML](https://whynpc9.github.io/ofdrw.net/guides/html-preview/) |
| 编辑已有文档 | [文档工具](https://whynpc9.github.io/ofdrw.net/guides/document-tools/)、[文字定位与替换](https://whynpc9.github.io/ofdrw.net/guides/keyword-replacement/) |

| 查询参数和限制 | [CLI](https://whynpc9.github.io/ofdrw.net/reference/cli/)、[SDK 入口](https://whynpc9.github.io/ofdrw.net/reference/sdk/)、[能力矩阵](https://whynpc9.github.io/ofdrw.net/reference/feature-parity/) |

## 版本范围

当前公开版本为 **0.1.0-preview.10**。[发布说明](https://whynpc9.github.io/ofdrw.net/releases/010-preview10/)记录该版本的能力、依赖和验收范围。

本站同时维护当前 main 的实现约定。标注“main / 尚未发布”的功能不能由安装 preview.10 获得；详细差异见[已知问题](https://whynpc9.github.io/ofdrw.net/troubleshooting/known-issues/)。可选 PDF Vector、Skia、SES interop 和 Password 扩展不在默认 12 包的发布集合中。

## 2026-10-23 repeated-page metadata review fix

- Review of `51b168d` found that attachment import repeatedly walked the raw PDF page tree from its root for every selected occurrence. The importer now maintains one document-scoped, monotonic raw-page lookup, reuses parsed annotations and page objects by source index, and still creates and charges each output attachment occurrence separately. The optional vector importer performs one short-lived annotation preflight for distinct selected source pages before its per-page parser/resource stores; its final metadata pass also uses the document-scoped lookup. A lookup is rejected if paired with a different `PdfDocument`.

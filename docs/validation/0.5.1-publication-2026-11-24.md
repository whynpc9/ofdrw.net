## 功能测试

本地全套 .NET 回归 5,490 通过、4 跳过、0 失败。固定字体补跑覆盖其中两项 CJK 用例。强制可信字体门禁 74 项通过。14 个候选包和 SES 扩展均通过独立消费。脚本测试、许可清单、已披露依赖告警和公开 API 文档检查通过。

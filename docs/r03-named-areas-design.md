# R03 命名区域设计与验收矩阵

基线：R00 merge `35976dbee1f58eef5fe19f2750746a97d523cfec`。本页在实现前记录首版契约；研究报告 v1.2 是静态候选，不是验收。

`AreaHolderBlock` 是占据内容区全宽、指定高度的不可拆分页块。它进入 `FlowDocument.Render` 的排版流程，最终页面与 Boundary 才写入区域索引。仅包含命名区域的 Flow 输出为各页指定稳定数字 ID。索引放在 `CustomTags` 的保留键 `ofdrw.net.named-areas.v1`，值为有界、版本化 XML；这是 SDK 私有持久格式，**不宣称与 Java 的 AreaHolderBlocks.xml 或其它阅读器的编辑接口互通**。选此载体是因为现有 Writer/Reader 已对 CustomTags 做保存重开、未知槽保留和路径冲突防护，避免此票另造未受验的 OFD 扩展文件写入路径。保留键已占用、重复索引、页序号/ID 不匹配、无效/越界框一律拒绝。页重排、合并、拆分后若索引失效，回填拒绝；不猜测新位置。

`OfdNamedAreaEditor` 在读取索引后提供查询、`FillText` 和 `FillImage`。一次回填后状态标为 filled，重复填充拒绝，防止叠印。文字使用明确的 `LegacyApproximate` Flow 度量与分行；不承诺真实字体轮廓或复杂脚本 shaping，待 R21 能力合并后才增加独立精确模式。行宽、总高、字符数先预检；超出即失败，源包不变。图片接受有界 PNG/JPEG 数据及调用者提供的像素宽高，按 contain 等比放入区域；像素尺寸是调用者声明，此 API 不进行解码验真。目标 `Stream` 仍受 R00 的非回滚契约约束，应用层文件须采用原子提交。

| 门 | 正样本 | 反样本/不变量 |
| --- | --- | --- |
| 布局 | 前文、占位、后文，跨页占位；最终页和框 | 重名/非法名/超页高度；区域外原文坐标不变 |
| 持久 | Render→Write→Read→按名查询→填字/图→Write→Read | 未知名、重复回填、页序/ID 或框篡改拒绝 |
| 适配 | 中英文与比例英文、局部样式、表格、分页的固定文档；文字和图片各一块 | 溢出文字、无效图片、超字节/像素预算；失败无部分回填 |
| 输出 | OFD 原文完整；本次 OFD→PDF→全部受影响页 PNG 和 Preview | 区域外无漂移、无裁切/重影/异常空白；PNG 和 Preview 分别记载 |
| 回归 | 定向 Layout/Reader/Packaging；共享布局全套回归和本地包消费 E2E | 当前 head CI、bot 审阅、线程均关闭后才合并 |

R03 仅改变本 SDK 生成的命名区域文档。现有普通 Flow、任意外部 OFD、签名文档、跨文档迁移和二次替换不自动获得此能力。

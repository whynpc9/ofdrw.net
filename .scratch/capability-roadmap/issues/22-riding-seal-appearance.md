## What to build

骑缝章首先是几何：印章图被切到相邻页边，合起来能对上。这张票用 06 的定位（以及现有图元）把外观放到对的地方。它不创建 SES、不改 `FullyValid`、不冒充生产签章。

## Acceptance criteria

- [ ] API 能按页边规则放置骑缝/对开图片或图章外观；相邻页拼起来图形连续（样例可验收）
- [ ] 输出包里这是页面外观对象，不是自动生成的有效 `SignedValue.dat`
- [ ] 文档写明：外观 ≠ 签名值，无法律效力，无阅读器互认
- [ ] 有样例；更新功能对照时不得把该项标成生产签章

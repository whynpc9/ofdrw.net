# 关键字定位与文档内容替换

**What to build:** 从已有 OFD 的 `TextObject` 重建字形框，按关键字返回页码和毫米坐标；再按这些位置替换文字。替换后版面不塌，摘要/签名约定写清楚。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 关键字查询返回页码与毫米框，供盖章和替换使用
- [ ] 替换后版面不塌；对已签名包的摘要约定有说明
- [ ] 有样例与往返检查

[docs/capability-roadmap.md](../../../docs/capability-roadmap.md) P1-05、P1-06

## What to build

盖章和回填需要「这两个字在哪」。先从页面文字对象恢复字形框并做关键字命中，再提供内容替换。这是一条垂直能力：定位结果必须真能驱动一次替换演示。替换不是重排整篇；目标是原地改字、对齐不崩。若包上有签名，文档必须说明摘要会失效、需要重签，而不是默默留下假完整签名。

## Acceptance criteria

- [ ] API 对样例包中的已知关键字返回页码与毫米坐标框；未命中为空而不是抛成内部错误
- [ ] 可按关键字或定位结果替换文字；替换后邻行/邻对象不重叠、不丢字；抽出文本含新内容、不含旧关键字（按样例约定）
- [ ] 文档说明：改字节后保护引用与签名如何处理（与现有「重写即失效签名」一致）
- [ ] 有无隐私样例；更新功能对照
